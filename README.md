# Unemployment Analysis with Python

## Project Overview

This project analyzes unemployment trends in India using Python.
The analysis focuses on unemployment rates during the Covid-19 period and identifies important patterns, regional differences, and employment trends through data visualization.

---

## Objectives

* Analyze unemployment rate data.
* Perform data cleaning and preprocessing.
* Visualize unemployment trends using graphs.
* Investigate the impact of Covid-19 on unemployment rates.
* Identify key patterns and regional unemployment variations.
* Generate insights that can help in economic and social policy planning.

---

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Lab

---

## Dataset Used

* Unemployment_Rate_upto_11_2020.csv

The dataset contains:

* Date
* Region
* Estimated Unemployment Rate (%)
* Estimated Employed
* Labour Participation Rate

---

## Project Workflow

1. Import required libraries
2. Load the dataset
3. Clean missing values
4. Convert date column
5. Analyze unemployment trends
6. Create visualizations
7. Study Covid-19 impact
8. Generate insights

---

## Data Visualizations

The project includes:

* Line Plot of unemployment trends during Covid-19
* State/Region-wise unemployment bar graph
* Correlation heatmap

---

## Key Insights

* Unemployment rates increased significantly during the Covid-19 lockdown period.
* Some regions experienced higher unemployment compared to others.
* Economic slowdown during the pandemic affected employment opportunities across the country.

---

## Conclusion

This project demonstrates how Python can be used for data analysis and visualization to understand real-world economic problems.
The analysis helps identify unemployment trends and the impact of Covid-19 on employment rates in India.
